Paleta de cores

Fundo escuro para uma ferramenta de uso continuo por quem desenvolve. As cores de status e prioridade sao diferentes da cor de destaque, para nao confundir "botao clicavel" com "prioridade critica".

Tipografia

Uma unica fonte do Google Fonts (JetBrains Mono) nos titulos, ligada ao editor JetBrains WebStorm liberado pela disciplina. O texto corrido usa Arial/Helvetica, igual aos exemplos vistos em aula.

Titulo - JetBrains Mono Painel de Demandas
Texto - Arial / Helvetica

O Lider de Projeto pode reatribuir o responsavel, alterar a prioridade e mover a demanda entre os status previstos no fluxo de trabalho, respeitando as permissoes de cada perfil de acesso.

Como aplicar

Coloquem os hex abaixo direto no CSS de cada tela (igual aos exemplos das aulas - sem variavel, sem :root). O mais facil e cada um copiar essa lista de cores e reusar nos proprios seletores.

<!-- no head de cada pagina -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;700;800&display=swap">

/* cores principais do sistema Nexo */
/* fundo: #0a0a0f          superficie: #15141c */
/* texto: #edecf3          texto secundario: #9a97ac */
/* destaque (botoes/links): #6d4aff   hover: #8566ff */

/* status: aberta #4ea1ff, andamento #f5a623, revisao #2dd4bf, concluida #34d399, cancelada #8d899c */
/* prioridade: critica #ff5470, alta #ff9f40, media #ffd166, baixa #8b98a8 */
"nexo" e um nome provisorio - troquem no cabecalho, no README e no repositorio quando o grupo decidir o nome final do sistema. A paleta e a fonte continuam valendo.
